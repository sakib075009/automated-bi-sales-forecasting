# Automated Business Intelligence & Sales Forecasting Platform

## Project Overview

This project develops an automated business intelligence and sales forecasting platform using Python, Power BI, GitHub Actions, and GitHub Pages.

The system uses synthetic retail/e-commerce transaction data to demonstrate:

- Business intelligence
- Sales analytics
- Customer analytics
- Product analytics
- Forecasting
- Automated insights
- Scheduled data generation
- Dashboard automation

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Statsmodels
- Power BI
- Git
- GitHub Actions
- GitHub Pages
